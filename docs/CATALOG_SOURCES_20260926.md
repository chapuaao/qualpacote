## Regras de modelação

- Informação ausente não é inventada.
- Horários são decompostos em benefícios separados.
- Dados exclusivos de aplicações são separados de internet geral.
- Carteiras partilhadas de minutos/SMS são modeladas como uma única quantidade, nunca duplicadas.
- Aditivos que exigem um plano base são marcados como condicionais.
- Quotas diárias não acumuláveis são limitadas ao número de dias que o utilizador efectivamente pretende cobrir.
- Quando uma fonte publicar FUP, a capacidade a velocidade normal é explicitada e a redução posterior é apresentada ao utilizador.
