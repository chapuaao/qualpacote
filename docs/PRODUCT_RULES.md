# Regras do produto

## Linguagem pública

Usar frases curtas e concretas, como “Quanto quer gastar?”, “O que mais precisa?” e “Melhor encaixe”. Evitar linguagem técnica, interna ou sobre o processo de desenvolvimento.

## Neutralidade comercial

O QualPacote não promove uma operadora. A ordenação aplica as mesmas regras a todas as redes. A operadora não pode comprar posição no ranking; eventual conteúdo patrocinado deve ficar separado da recomendação.

## Explicabilidade

Toda recomendação deve mostrar custo para o período, capacidade útil estimada, cobertura do período, restrições relevantes e fonte.

## Dados insuficientes

Quando não houver plano verificado para uma rede, mostrar ausência de opção. Não preencher lacunas com estimativas inventadas.

## Precisão

Não usar “melhor” de forma absoluta. O resultado representa o melhor encaixe para os parâmetros informados e os dados verificados no catálogo.
